## MomoStory v1.0.3

### 주요 변경 사항

- 라이브러리 카드에서 채팅과 인연스토리를 이어지는 MP4로 추출합니다. 16:9와 9:16을 지원합니다.
- 영상에서 선택지는 자동으로 진행하며, AUTO 글자는 표시하지 않습니다.
- 타이틀 펼침·페이드, 캐릭터 모션, 감정 아이콘, 화자 소속과 효과음 등 영상 연출을 보완했습니다.
- PC 영상 추출은 파일명과 저장 위치를 먼저 고른 뒤 생성합니다. 모바일 TXT 추출·불러오기도 수정했습니다.
- 라이브러리에 채팅 내역 저장·순차 재생, 새로 만들기, 제목/내용 검색을 추가하고 그리드를 개선했습니다.
- 모바일 생성 로딩 위치와 스토리 진행 터치를 개선하고 설정에 채팅 크기 조절을 추가했습니다.
- 언어 설정에 따라 새 채팅과 스토리를 한국어·영어·일본어·중국어(간체)로 생성하도록 연결했습니다. 기존 저장본은 원문을 유지합니다.
- Android 감정 아이콘 리소스의 확장자와 실제 이미지 형식을 일치시켰습니다. 기존 대본의 아이콘 이름은 그대로 사용할 수 있습니다.

### 다운로드

- Windows: `MomoStory.exe` 또는 `MomoStory_1.0.3_x64-setup.exe`
- Android: `MomoStory.apk`

Gemini API 키는 포함하지 않습니다. 설치 후 설정에서 본인의 키를 입력해 주세요.
Android는 새 APK로 업데이트해야 영상 저장 기능이 포함됩니다.
